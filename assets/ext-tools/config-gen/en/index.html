Configuration parameter generator

A desktop-class generator for the complete device parameter set. Fill in what you need, and it produces an online command, an importable config.xml, or a QR code — all computed in your browser.

Open the generator → I only need the basics
The generator's interface is in Chinese. Every field shows its XML tag right next to the label (for example ucFD_TimeZone), and the search box at the top accepts tag names — so you can jump to a parameter even if you don't read Chinese. The sections below map the module names and the most common tags.

What it produces

Online command

A <Control>…</Control> DEVICE_SET command you can paste into your platform and push to a device.

config.xml

A <VariCfgSec> file for SD-card / USB import. Only the fields you edited are written.

QR code

For devices that support scan-to-import. Point the camera at the screen; no network needed on the device.

Reverse parsing

Paste an existing config.xml or command back in and the form refills — handy for cloning a unit.

How to use it

  1. Pick a module in the left sidebar, then a sub-page in the drop-down.
  2. Edit only the fields you need — untouched fields are not written into the output. A counter at the top shows how many fields you have changed.
  3. Read the result on the right: switch between online command and import config; the byte and field counts update live.
  4. Copy the command, download config.xml, or generate the QR code.

To start from an existing unit instead, click 配置反解析 (top right), paste the file or command, then apply the parsed values back into the form.
